# Teaching data

The files in this directory are generated by `scripts/generate_synthetic_data.R` with fixed random seeds.

- `toy_counts.csv` — six genes by four cells for hand calculations.
- `synthetic_qc_counts.rds` — sparse gene-by-barcode UMI matrix.
- `synthetic_qc_metadata.csv` — sample labels and controlled truth used for QC sensitivity teaching.
- `synthetic_data_manifest.csv` — dimensions, file sizes, and SHA-256 checksums.

The synthetic QC dataset includes retained cells, low-quality profiles, stressed cells, ambient-contaminated profiles, simulated doublets, and empty droplets. It contains no human-subject or clinical data.

Regenerate deterministically:

```bash
Rscript scripts/generate_synthetic_data.R
```

Verify committed files without overwriting them:

```bash
Rscript scripts/generate_synthetic_data.R --check
```
